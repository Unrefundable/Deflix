Deflix

A Kodi skin with a streaming-focused layout. Install the repository once, then install and update Deflix from Kodi's add-on browser.

Download repository zip Download skin zip

Kodi Install

  1. In Kodi, enable Unknown sources under Settings > System > Add-ons.
  2. Add this file source: https://unrefundable.github.io/Deflix/
  3. Open Add-ons > Install from zip file, choose the source, then install repository.deflix-1.0.1.zip.
  4. Open Install from repository > Deflix Repository > Look and feel > Skin > Deflix.
